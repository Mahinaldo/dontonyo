## Required source anomalies

1. Page 569 says socialism was established in China in **1971**; the historical political transition belongs to 1949. The line is never imported as an independent fact.
2. Page 569 says China regained UN `permanent membership` in 1971. Resolution 2758 concerns representation; this compressed wording remains caveated.
3. Page 570 calls the 14th Dalai Lama `চতুর্থ` (fourth), whereas the source-page visual context names the 14th Dalai Lama. The error is not normalized into a factual record.
4. Page 571’s OCR calls the Taiwan waterway `Formosa Strait`; no modern geography label is silently substituted. The cross-strait material remains source-attributed.
5. Page 572 prints a footer number inconsistent with the physical PDF-page sequence. The importer uses physical source page **572** and preserves the source image checksum.
6. Page 573 OCR corrupts Q06, Q07, Q10, Q13, and Q16. The ledger follows the ordered tile review; Q10/Q13 are withheld and Q06/Q07/Q16 use only the exact visually supportable wording.
